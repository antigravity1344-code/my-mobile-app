پاکشو — باز کردن در VS Code

این پوشه همهٔ فایل‌های پروژه است، بدون کتابخانه‌ها (node_modules).

۱) پوشه را از حالت فشرده خارج کنید.
۲) در VS Code: File → Open Folder و همین پوشه را انتخاب کنید.
۳) در ترمینال VS Code:

   npm ci

۴) بعد کتابخانه‌های سرور:

   cd server
   npm ci
   cd ..

۵) آزمایش برنامه:

   npm test
   npm run typecheck

برای آزمایش سرور به Node نسخهٔ ۲۴ نیاز است.

برنامهٔ روی گوشی شما هنوز این نسخه نیست. اول همین پوشه را روی کامپیوتر باز کنید.
