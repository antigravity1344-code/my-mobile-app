# پشتیبان‌گیری و انتقال داده‌های پاک‌شو

## آنچه پشتیبان شامل می‌شود
- دیتابیس کامل (سفارش‌ها، کاربران، کیف پول، تاریخچهٔ وضعیت‌ها، کدهای تخفیف، تنظیمات سرویس‌ها)
- فایل تعرفه (تاریخچهٔ کامل نسخه‌های تعرفه)
- مدارک کارگران (اختیاری، پیش‌فرض شامل است)
- فایل manifest.json با اندازه و کد sha256 هر فایل

## آنچه پشتیبان شامل نمی‌شود
- PAKSHO_DATA_ENCRYPTION_KEY: بدون این کلید، فیلدهای رمزشدهٔ دیتابیس خوانده نمی‌شوند. باید جداگانه و امن منتقل شود.
- PAKSHO_ADMIN_PASSWORD، کلیدهای پیامک و درگاه پرداخت، و فایل .env.

پشتیبان حاوی اطلاعات شخصی مشتریان و کارگران است. آن را فقط روی جای امن نگه دارید.

## دستورها (از پوشهٔ server اجرا شوند)
- ساخت پشتیبان: npm run backup -- <مسیر پوشهٔ جدید خالی>
- بررسی صحت: npm run verify-backup -- <مسیر پشتیبان>
- بازیابی: npm run restore -- <مسیر پشتیبان>
- بازنویسی داده‌های موجود: npm run restore -- <مسیر پشتیبان> --force (فقط با تصمیم آگاهانه)

مسیرها از همان متغیرهای PAKSHO_SQLITE_PATH، PAKSHO_TARIFF_FILE و PAKSHO_WORKER_DOC_DIR خوانده می‌شوند.

## ایمنی بازیابی
- پیش از هر کاری، صحت همهٔ فایل‌ها بررسی می‌شود؛ پشتیبان خراب یا دستکاری‌شده هیچ‌چیز را تغییر نمی‌دهد.
- بدون --force، اگر مقصد از قبل داده داشته باشد، بازیابی متوقف می‌شود.
- دیتابیس اول در یک فایل موقت کپی و بررسی می‌شود و سپس جایگزین می‌گردد.

## راهنمای انتقال به سرور جدید
1. روی سرور فعلی: npm run backup -- <پوشهٔ خروجی>
2. پوشهٔ خروجی را با روش امن به سرور جدید منتقل کنید.
3. روی سرور جدید: npm run verify-backup -- <پوشه>
4. متغیرهای محیطی را تنظیم کنید؛ PAKSHO_DATA_ENCRYPTION_KEY باید همان کلید منبع باشد.
5. روی سرور جدید: npm run restore -- <پوشه>
6. سرور را اجرا کنید و با یک سفارش آزمایشی و ورود مدیر بررسی کنید.
7. آدرس سایت و اپ را به سرور جدید وصل کنید و PAKSHO_CORS_ORIGINS را به‌روز کنید.

## محدودیت فعلی
انتقال مالکیت شرکت یا پنل داخل برنامه در این مرحله ساخته نشده است.
